# 智选车计划部数据平台 · PlanHub

统一访问 SOP 计划看板、订单分析、销量预测与数据速查。门户维护导航、入口、挂载/代理和通用启动部署逻辑；各业务网页的源码、UI、数据及规则继续由各自项目维护。

## 本地使用

环境要求：Node.js 20+、按原项目依赖重建的共享 Python 环境（工作区至少 Python 3.11）。不要从旧电脑复制虚拟环境。所有示例磁盘路径以门户根目录为基准，默认原项目与共享数据保持同级布局。

- 双击 `启动本地门户.cmd`，或运行 `npm start`；按终端打印的地址访问。
- 首次运行保留启动窗口。同一工作区、相同代码和配置的健康门户会被重复启动复用。
- 完整重启时先双击 `停止本地门户.cmd`，或运行 `npm stop`，再启动。后台实例也用停止入口结束；关闭另一个旧窗口不会停止它。
- 其他页面无法打开时运行 `npm run diagnose`，逐项检查本机路径、发布文件、依赖和服务。
- SOP 和数据速查默认使用各自原项目的持久数据；保存后重启保留。订单分析和销量预测默认直接读取原项目生成的发布物。
- 不同电脑先确认 `git remote -v` 指向本门户仓库；文件夹叫“计划工作台”不代表其中一定是 PlanHub。

具体环境、数据位置、本机配置、迁移和故障处理统一放在[使用指南](docs/usage.md)。当前仍是本机运行方案，部门 Windows 电脑的正式部署另按部署指南实施和验收。

## 开发约定

修改后运行相关必要检查；门户配置与脚本校验用 `npm run check`，行为变化运行对应测试。仅提交本次授权的门户文件，验证通过后默认提交并推送上游。业务数据、真实报表、日志、机密和临时产物不提交公开仓库。不自动部署、改仓库可见性、重写 Git 历史或修改 IIS/安全设置。
