# 文档目录

先按任务选一本；同类说明已合并，当前规则与历史记录分开维护。

| 你要做什么 | 阅读文档 |
|---|---|
| 启动/停止、找数据、换电脑、排查页面问题 | [使用、数据与排查](usage.md) |
| 开发一个可接入的网页，或把网页接到门户 | [应用接入手册](child-app-developer-guide.md) |
| 部署到部门 Windows 电脑 | [Windows 内网部署](deployment.md) |
| 查以前改过什么、备份在哪、哪些验证做过 | [实施与验证档案](history.md) |
| 调整门户颜色、布局或图标 | [统一设计规范](../design-system/planning-portal/MASTER.md) |

给其他网页开发者或他们的 AI，只需发[应用接入手册](child-app-developer-guide.md)。该地址保留不变；手册内按角色区分开发者要求、门户维护步骤和两类 AI 任务。

设计参考图片仍放在 `design/`，由统一设计规范引用；运行图标位于 `portal/assets/`。
