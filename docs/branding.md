# 计划部工作空间图标

图标采用用户于 2026-11-04 确认的[开口 P 精修稿](design/reference-open-p-approved.png)，对应自由造型第 3 款的细化版本。P 对应 Planning：上半部为不对称的深蓝开口圆腹，下半部为垂直向下的亮蓝竖笔，连接处增加少量浅蓝折面和蓝色层次。竖笔底端圆角平收，不得向左撇；保持开放的内侧留白，不改成普通闭口字体 P。

该图标替代此前的蓝底白色折带 P。门户继续采用 FinanceFlow 参考的白底灰蓝风格与紧凑顶部导航，完整名称为“智选车计划部数据平台”。后续品牌与界面修改以[设计基准](../design-system/planning-portal/MASTER.md)和本确认稿为准，不自行换字形、翻转笔画或添加箭头、图表等装饰。

应用位置：门户顶部品牌区、浏览器标签页、移动设备收藏图标及 README。图标文件保持原名称，生产主资产为 `portal/assets/planning-icon.svg`。确认图片仅作设计参考，不作为运行时外部资源。生产图形以矢量路径重建，去掉预览外围多余留白，保留圆腹、开口、直竖和折面的关系。

SVG、PNG、ICO 共用 `scripts/export-planning-icon.py` 的几何定义及颜色，白色圆角底的角外透明；不依赖操作系统字体或外网资源。需要更新生产资产时，编辑该导出器并执行 `python scripts/export-planning-icon.py`，生成门户的 SVG、512/180/32 像素 PNG 和含 16/32/48/64 像素尺寸的 ICO。Pillow 仅用于开发导出，不是门户或 SOP 的运行依赖。更新后同步修改 `portal/index.html` 的图标资源版本参数，避免旧缓存。

顶栏沿用既有 36×36 显示尺寸；图标旁已有平台文字，因此 HTML 中保留空 `alt` 和 `aria-hidden`，避免读屏重复播报。浏览器图标不加小字；验收时检查 16/32 像素的 P 轮廓、内侧开口和垂直竖笔仍清楚。白色底板保证深色浏览器标签栏中的可见性。

本次仅更新门户自己的品牌资产及规范。SOP 和其他子应用的图标由各自原项目维护，门户导出器不写入子应用，不修改其发布产物或业务数据；也不创建或修改操作系统快捷方式。
