# 计划部工作台 · 界面设计基准

工作台以 [Shopeers 设计作品](https://dribbble.com/shots/26628350-Shopeers-AI-Powered-B2B-eCommerce-Analytics-Dashboard) 为视觉依据。品牌保留用户确认的自由开口 P 和完整名称“智选车计划部工作台”。[品牌参考图](../../docs/design/reference-open-p-approved.png)

## 参考图与布局

- 门户沿用参考图的白色侧栏和浅灰画布。首页标题使用完整名称“智选车计划部工作台”。桌面标题下方并排展示四张阶段卡。阶段卡显示 01–04 编号。中部左栏展示工作清单和 SOP 记录入口，右栏展示订单日历。底部列出全部业务应用。
- 门户使用贴边的左侧图标栏，默认桌面 56px、640px 及以下 48px，展开宽度为 145px，与正文并排。内容区从顶边开始。选中项使用浅蓝背景和蓝色文字。
- 入口保留 44px 点击区、可读名称和可见焦点。展开后显示应用名称，待接入和维护中的入口以圆点提示。展开和收起由按钮切换。浏览器记住选择，切换应用及刷新时保持。
- 内嵌业务页统一使用顶部导航。各业务仓库维护自身布局、图标、表格和图表。门户通过注册表、同源 iframe 与正式接入接口展示页面。
- 手机上阶段卡分两列，工作清单、记录入口、订单日历和应用目录依次单列排列，较长的名称和介绍允许换行。业务页在各自的窄屏断点换行或折叠导航，宽表格在表格区滚动。

## 颜色与字级

| 语义 | 颜色 |
| --- | --- |
| 画布 | `#F4F6F9` |

| 正文与标题 | `#0B0D17` |
| 辅助文字 | `#606775` |
| 描边与分隔线 | `#E5E7ED` |
| 主操作与图表首选 | `#2859F5` |

使用本地 Segoe UI、Microsoft YaHei、PingFang SC 与系统无衬线字体。平台 P 在侧栏、浏览器标签与收藏图标中均使用透明底。页标题优先使用本机 Noto Sans SC。侧栏导航沿用初版字体栈，优先使用 Segoe UI，中文回退至 Microsoft YaHei。展开侧栏首行并排展示标志和“智选车”，下方以 19px、600 字重展示“计划部工作台”，沿用页标题的无衬线字体。左侧导航图标为 22px，展开时文字为 16px。选中入口使用浅蓝底和钴蓝线性图标，折叠按钮位于底部。

从工作台打开业务页时，子应用隐藏自己标题左侧的产品图标，标题从原图标的位置开始。独立打开同一网页时显示原图标。内嵌页标题字重为 700、行高为 1.15。页面主标题和内嵌页产品名为 19px，面板标题 16px，正文、导航及控件 14px，表格 13px，辅助信息 12px。页面主标题用 700 字重，面板标题用 650–700 字重。日期和指标使用等宽数字。实际图表以钴蓝为首选，比较序列保留足够区别，状态沿用业务语义和文字标识。

## 组件与交互

- 卡片圆角约 18–20px，使用 1px 描边和轻阴影。桌面面板间距通常为 16px，内容外边距为 24px，窄屏缩至 10–12px。白色卡片、清晰对齐和浅色分割线构成主要层次。
- 摘要卡以白底突出数值，选中状态由细描边和状态标签共同表示。表头使用浅中性色，当前月份用浅蓝突出。常用按钮、日期和过滤器采用胶囊形。主操作使用钴蓝。图标沿用一致的 SVG 线性风格。表格和清单用轻分隔线和浅蓝悬停或选中背景。
- 桌面内嵌页的顶部工具行高 64px，下面的导航行高 56px（含底部分隔线）。侧栏收起和展开时，品牌区和工作台入口分别采用相同的两行高度，分隔线在距顶部 120px 处与业务页导航底边齐平。导航底边到首个可见看板内容为 16px，屏宽 640px 及以下为 12px。桌面长导航保持单行滚动。窄屏按可用宽度排布：订单分析和车型配置使用模块下拉框，销量预测的阶段、视图和操作可分行显示。
- 主导航使用白色表面、10px 圆角和至少 44px 高的点击区。侧栏子应用入口间距 16px，图标为 22px，与文字间隔 6px。展开时导航文字 16px、400 字重，默认灰色；悬停使用画布灰底和标题色，选中使用浅蓝底和深蓝文字，键盘焦点用 2px 钴蓝轮廓。
- 卡片、标题和导航不使用粗装饰色条，选中状态通过浅色背景、文字和细描边表达。
- 参考图只定义静态外观。悬停采用约 160ms 变色，保持布局稳定。支持可见键盘焦点和减少动态效果偏好。手机主要操作保持约 44px 点击高度。
- 已成功打开的业务 iframe 在应用切换时保留，所有应用使用同一规则；失败、超时和重试重新加载。只显示当前 iframe，隐藏页面不可参与键盘导航；数据更新仍由子应用负责。
- 桌面和窄屏均让业务页面填满侧栏右侧的可用区域。门户嵌入容器采用零内边距、直角、无描边和阴影。
- 应用路由、加载与错误状态沿用已有规则。正常应用内容区为业务 iframe，待接入入口显示真实接入状态。

## 首页阶段清单与应用目录

选择阶段卡会切换工作清单。清单项用于进入对应业务网页，门户不记录任务勾选或完成进度。右栏月历以周一为首日，左侧标记 ISO 周次。手工批注按事件日期展示，跨主体重复的阶段事件按日期和文字合并；点击有标注的日期可读取完整内容，编制周期和已保存的计划记录由 SOP管理提供，记录入口打开该应用。

底部应用目录和侧栏共用 `portal/config/apps.json` 的应用注册信息。每个已启用应用显示名称和简短介绍，可用的链接通过门户路由打开对应网页。待接入或维护中的网页显示实际状态。

## 品牌与验收

品牌的 SVG、PNG、ICO 以 `portal/assets/planning-icon.svg` 为主。2026-11-09 将 P 的竖笔向下延长 4.8 个画布单位，保留笔直平收的轮廓，并调整图形的垂直留白。浏览器标签采用透明底的 `favicon.svg`、`favicon.ico` 和 32px PNG。导出器为 `scripts/export-planning-icon.py`。旧版布局及实施记录通过 Git 历史查阅。

运行 `npm run check` 与 `npm test`。在浏览器查看桌面、手机和断点附近截图，核对阶段切换、清单内容、日历周次和标注、记录和目录链接、溢出、键盘焦点、各应用嵌入和待接入提示。使用隔离数据验证业务视图。

真实页面验收从已启动的工作台进入子页，在 1440px 和 390px 下检查背景、标题、导航选中态、键盘焦点和可见区域，命令见[项目首页](../../README.md#开发联调)。原生下拉导航检查实际模块切换。

外壳导航回归单独检查这两种宽度下的展开、收起、边界和圆角。固定样例截图位于 `tests/visual-baselines/`，仅使用测试导航。确认视觉变更后，在 Windows Edge、Playwright、Pillow 环境中设置 `PLANHUB_UPDATE_VISUAL_BASELINES=1`，运行 `tests/test_app_navigation.py` 的 unittest 发现命令更新，然后清除该变量并复测。
