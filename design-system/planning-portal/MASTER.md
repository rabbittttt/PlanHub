# 计划部数据平台 · 界面设计基准

2026-11-10 更新。工作台以 [Shopeers 设计作品](https://dribbble.com/shots/26628350-Shopeers-AI-Powered-B2B-eCommerce-Analytics-Dashboard) 为视觉依据。品牌保留用户确认的自由开口 P 和完整名称“智选车计划部数据平台”。[品牌参考图](../../docs/design/reference-open-p-approved.png)

## 参考图与布局

- 参考图以白色侧栏和顶栏围住浅灰画布。内容上方为四个独立指标卡，下方为约六四比例的双列面板。采用这一网格呈现计划周期、工作清单、计划窗口与记录。
- 门户使用贴边的左侧图标栏，默认桌面 56px、640px 及以下 48px，展开宽度 145px，与正文并排。内容区从顶边开始。选中项使用浅蓝背景和蓝色文字。
- 入口保留 44px 点击区、可读名称和可见焦点。展开后显示应用名称，待接入和维护中的入口以圆点提示。展开和收起由按钮切换。浏览器记住选择，切换应用及刷新时保持。
- 内嵌业务页统一使用顶部导航。各业务仓库维护自身布局、图标、表格和图表。门户通过注册表、同源 iframe 与正式接入接口展示页面。
- 手机阶段卡按两列换行，清单、窗口和记录按阅读顺序单列排列。业务页在各自的窄屏断点换行或折叠导航，宽表格在表格区滚动。

## 组件与交互

- 卡片圆角约 18–20px，使用 1px 描边和轻阴影。桌面面板间距通常为 16px，内容外边距为 24px，窄屏缩至 10–12px。白色卡片、清晰对齐和浅色分割线构成主要层次。
- 常用按钮、日期和过滤器采用胶囊形。主操作使用钴蓝。图标沿用一致的 SVG 线性风格。表格和清单用轻分隔线和浅蓝悬停或选中背景。
- 卡片、标题和导航不使用粗装饰色条，选中状态通过浅色背景、文字和细描边表达。
- 参考图只定义静态外观。悬停采用约 160ms 变色，保持布局稳定。支持可见键盘焦点和减少动态效果偏好。手机主要操作保持约 44px 点击高度。
- 已成功打开的业务 iframe 在应用切换时保留，所有应用使用同一规则；失败、超时和重试重新加载。只显示当前 iframe，隐藏页面不可参与键盘导航；数据更新仍由子应用负责。
- 应用路由、加载与错误状态沿用已有规则。正常应用内容区为业务 iframe，待接入入口显示真实接入状态。

## 计划周期演示

首页阶段、清单、窗口和记录使用明确标注的 Demo。演示交互仅存在页面内存，重置和刷新恢复初始状态。演示内容仍由 `portal/js/workbench-demo.js` 管理。实际应用的入口和状态来自 `portal/config/apps.json`，业务数据与功能由各自应用提供。

## 品牌与验收

品牌的 SVG、PNG、ICO 以 `portal/assets/planning-icon.svg` 为主。2026-11-09 将 P 的竖笔向下延长 4.8 个画布单位，保留笔直平收的轮廓，并调整图形的垂直留白。浏览器标签采用透明底的 `favicon.svg`、`favicon.ico` 和 32px PNG。导出器为 `scripts/export-planning-icon.py`。旧版布局及实施记录通过 Git 历史查阅。

运行 `npm run check` 与 `npm test`。在浏览器查看桌面、手机和断点附近截图，核对分栏比例、卡片密度、溢出、键盘焦点、演示交互、各应用嵌入和待接入提示。使用隔离数据验证业务视图。
